# Event Horizon

**An interactive browser-based puzzle game built with HTML, CSS, and JavaScript.**

Event Horizon is a web-based game focused on interactive gameplay, clear visual presentation, and responsive user controls. Built with vanilla JavaScript, the project explores game logic, DOM manipulation, event handling, and frontend development without relying on a JavaScript framework.

## Features

- **Interactive Gameplay:** Play using the game's interactive circle-based board.
- **36-Circle Board:** A pyramid-style layout containing 36 circles, with 35 playable circles.
- **Game Controls:** Manage gameplay using the available in-game controls.
- **Pause and Resume:** Pause a session and resume playing when supported by the current game state.
- **Responsive Interface:** Designed to support different screen sizes and orientations, subject to the current implementation.
- **Vanilla JavaScript:** Built without a frontend framework.

## Tech Stack

- **HTML5** for structure and semantic markup.
- **CSS3** for styling, layout, and visual presentation.
- **JavaScript (ES6+)** for game logic, event handling, and interactivity.

## Getting Started

### Prerequisites

A modern web browser is all you need to play the game.

To modify the source code, use a code editor such as Visual Studio Code.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/m-faisal-askari/Event-Horizon
   ```

2. Navigate to the project directory:

   ```bash
   cd event-horizon
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in Visual Studio Code for local development.

## How to Play

1. Open Event Horizon in your browser.
2. Read the in-game instructions before starting.
3. Interact with the circle-based board to play.
4. Use the available game controls to manage your session.

The exact gameplay rules and win conditions are defined by the current game implementation.
